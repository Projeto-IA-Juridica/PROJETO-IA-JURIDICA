Próximos passos — Ativar o Agente
Siga o guia para conectar o escritório ao WhatsApp
  1. Abra o painel da Evolution API
    Acesse a URL da sua instância no navegador (ex.: http://seu-servidor:8080). Autentique com a EVOLUTION_API_KEY configurada no servidor.
  2. Crie ou selecione a instância do escritório
    Crie uma instância com o nome exato registrado em webhook_whatsapp_instance no banco.
    ⚠️ O nome deve ser idêntico — sem espaços ou variações de capitalização.
  3. Escaneie o QR Code com o WhatsApp
    Clique em Connect / QR Code na instância. No celular: WhatsApp → ⋮ → Dispositivos conectados → Conectar dispositivo.
    ✅ Status "open" confirma a conexão.
  4. Configure o Webhook
    Em Webhook da instância:
    URL → https://seu-dominio.com/webhook/whatsapp
    Eventos → marque MESSAGES_UPSERT e CONNECTION_UPDATE
    Header → apikey: SUA_EVOLUTION_API_KEY
    🔗 A URL precisa ser acessível publicamente.
  5. Aguarde as mensagens de boas-vindas
    Ao conectar, o sistema envia automaticamente uma mensagem de boas-vindas para todos os clientes importados.
    ✅ Cada cliente recebe apenas uma vez — reconexões não reenviam.
  6. Verifique os logs
    Se o agente não responder, consulte os logs da aplicação. Procure por webhook_mensagem_enfileirada e boas_vindas_escritorio_concluido.
Boas-vindas automáticas: ao conectar (status "open"), o agente envia automaticamente uma apresentação para todos os clientes importados. Após isso, responde qualquer mensagem relacionada ao processo do cliente. ⚖️
