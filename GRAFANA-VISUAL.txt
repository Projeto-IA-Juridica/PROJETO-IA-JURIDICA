ARQUITETURA
═══════════

  FastAPI (http://localhost:8000)
         │
         ├─ /metrics (Prometheus format)
         │
         ▼
  Prometheus (http://localhost:9090)
         │
         ├─ Coleta métricas a cada 10s
         ├─ Armazena em memória (30 dias)
         │
         ▼
  Grafana (http://localhost:3000)
         │
         ├─ Dashboard RAG
         ├─ Alertas
         └─ Visualização em tempo real


INSTRUÇÕES RÁPIDAS
══════════════════

1️⃣  Terminal 1 — FastAPI
    $ source .venv/bin/activate
    $ uvicorn feature_1_ia_personalizada.api.app:app --port 8000


2️⃣  Terminal 2 — Prometheus + Grafana
    $ cd monitoring
    $ bash quick-start.sh
    # Aguarde ~1 min para Docker fazer download


3️⃣  Acessar Grafana
    • URL: http://localhost:3000
    • User: admin
    • Pass: admin123


4️⃣  Ver Dashboard
    Dashboard → RAG Retriever — Métricas Prometheus


5️⃣  Testar Métricas (Terminal 3)
    $ source .venv/bin/activate
    $ python scripts/test_and_report_rag_metrics.py


PARAR TUDO
══════════

    Terminal 1: Ctrl+C
    Terminal 2: $ docker-compose -f docker-compose.monitoring.yml down

MÉTRICAS DO DASHBOARD
═════════════════════

📊 Contextos Ao Longo do Tempo
   • Injetados (✓) — Respostas com contexto RAG
   • Vazios (✗) — Buscas sem resultado

🎯 Taxa de Sucesso RAG (Hit Rate %)
   • Verde (≥70%) — OK
   • Amarelo (50-70%) — Revisar
   • Vermelho (<50%) — Problema

⚡ Latência de Busca (P50, P95, P99)
   • Identifica gargalos
   • Monitora degradação

💾 Cache Redis Hits
   • Taxa de acertos/segundo
   • Indica eficiência

📈 Estatísticas
   • Total de Buscas
   • Contextos Injetados
   • Contextos Vazios


DICAS
═════

✅ Métrica não aparece?
   • Aguarde 1-2 min (Prometheus leva tempo para coletar)
   • Execute testes: python scripts/test_and_report_rag_metrics.py
   • Refresque Grafana: F5

✅ Quer alertas?
   • Configure em Prometheus: monitoring/prometheus/rules.yml
   • Configure em Grafana: Alerting → Notification channels

✅ Quer em produção?
   • Use Grafana Cloud (sem gerenciar Docker)
   • Veja: cat monitoring/README.md
